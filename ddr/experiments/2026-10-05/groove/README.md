# Official footwork generation for Rare Earth

The final doubles in `selected-model-doubles/output/model-singles.sm` were
generated by PerryAsleep's **StepManiaChartGenerator 2.0.3**, using the same
StepManiaLibrary ExpressedChart/PerformedChart generation family used by
GrooveAuthor. This is the actual official path-search algorithm; no custom
footwork planner replaces it. The file also retains the four selected learned
singles unchanged.

GrooveAuthor has official Linux releases. Its separate chart generator's
README advertises Windows, but its console application runs headlessly here
after the documented portability adaptations in `provenance.json`: .NET 10
framework targets, bundled framework assemblies, and a Windows-only device
path prefix. A separate instrumentation patch writes the official chosen
foot assignments to JSON. It does not change generation decisions.

Source commits, official links, the Microsoft SDK download and verified SHA512,
and the three exact source patches are retained alongside this file.

From the repository root:

```bash
bash ddr/experiments/2026-10-05/groove/bootstrap.sh
python3 ddr/experiments/2026-10-05/groove/run_generator.py \
    ddr/experiments/2026-10-05/selection/model-singles.sm \
    --name selected-model-doubles
ddr/.venv/bin/python ddr/experiments/2026-10-05/groove/audit_generator.py \
    ddr/experiments/2026-10-05/groove/selected-model-doubles
```

The harness can also re-pattern singles with `--output-type single`. It reads
one SM/SSC source and always writes into this experiment directory. Run invocations
sequentially because the official application reads one configuration file
from its install directory. The official generator's random seed is derived
from the input filename; retaining the filename preserves that seed.

`ClassicLow`, `ClassicMedium`, and `ClassicHeavy` controls are saved in each
run's `config.json`. NoBrackets parsing treats jumps as two-foot jumps.
Distance/speed tightening favors short foot movements; facing penalties
discourage inward/outward facing; lateral tightening favors little sideways
movement during dense phrases. Transition preferences are 8–24, 12–40, and
16–56 steps respectively, with balanced use of both pads. These are search
preferences, so final output must be audited. Chart conversion preserves
source step types; it does not promise to remove technical patterns from
an arbitrary source.

For the final four doubles the audited official foot paths have:

| Difficulty | Step rows | Holds | Jumps | Full pad transitions | Max foot travel | Max foot speed |
|---|---:|---:|---:|---:|---:|---:|
| Beginner | 113 | 10 | 0 | 2 | 2.00 panels | 1.60 panels/s |
| Easy | 175 | 42 | 2 | 8 | 2.00 panels | 2.25 panels/s |
| Standard | 245 | 9 | 12 | 8 | 2.00 panels | 3.20 panels/s |
| Heavy | 419 | 0 | 1 | 27 | 2.24 panels | 6.40 panels/s |

Each uses all eight panels, retains all source notes and hold pairs, and never
demands more than two feet. All chosen graph nodes have normal body orientation;
there are zero brackets, crossovers, inverted moves, or footswaps. Maximum
stance width is 2.24 panel-center units. All five Heavy sixteenth-burst beats
stay on one pad. Travel and speed values use full panel-center distances,
including jump landings; the official generator itself uses smaller realistic
edge-trigger travel distances.

The exact 71 BPM segments and offset are verified after official writing.
The harness restores source timing string formatting after confirming equal
decimal values. Detailed checks and paths are in `audit.json` and the run's
`review/visualizations/` directory; HTML files show source and generated charts
with assigned feet. Software checks do not replace a physical pad playtest.

`baseline-proof/` records successful conversion of all four pre-existing
agent-authored singles, before generating doubles from the selected model
charts. `beginner-seed-17/` records the first model-candidate conversion.
